     • Ajoute role et permissions JSON

  5. apps/users/models/profil_nutritionnel.py
     • ProfilNutritionnel (OneToOne vers Client)
     • Calcule IMC, BMR, besoins caloriques
     • Recommande plats adaptés

🔧 COMMENT AJOUTER UN NOUVEAU MODÈLE
═════════════════════════════════════════════════════════════════════════════

1. Créer le fichier:
   $ touch apps/app/models/nom_classe.py

2. Remplir le fichier:
   """
   Modèle NomClasse - Description
   """
   from django.db import models
   
   class NomClasse(models.Model):
       # Fields
       
       class Meta:
           db_table = "app_nomclasse"

3. Mettre à jour __init__.py:
   from .nom_classe import NomClasse
   
   __all__ = [
       ...
       'NomClasse',
   ]

4. Vérifier models.py:
   (doit automatiquement inclure la nouvelle classe)
