## 💬 QUESTIONS FRÉQUENTES

### Q: Comment tester la navbar?
A: Exécutez `python manage.py runserver` et ouvrez http://localhost:8000

### Q: Comment changer les couleurs?
A: Modifiez les variables CSS dans `static/accueil/style.css`

### Q: Comment ajouter un lien?
A: Consultez NAVBAR_GUIDE.html (Exemple 2) ou README_NAVBAR.md

### Q: Comment activer le mode sombre?
A: Ajoutez `navbar-theme-dark` à la classe de la navbar

### Q: Est-ce responsive?
A: Oui! Menu hamburger sur mobile (<992px), testé sur tous appareils

### Q: Est-ce accessible?
A: Oui! WCAG AAA, navigation au clavier, ARIA labels

### Q: Comment vérifier l'installation?
A: Exécutez `python verify_navbar.py`

### Q: Quels navigateurs sont supportés?
A: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+, mobiles

### Q: Est-ce performant?
A: Oui! Bundle ~3KB gzipped, animations GPU-friendly, <50ms load

### Q: Puis-je personnaliser les icônes?
A: Oui! Utilisez Font Awesome ou Bootstrap Icons
