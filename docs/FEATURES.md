# Features

## User Authentication
- User registration and login
- Password reset functionality
- Profile management

## Menu Management
- Browse available dishes
- Filter by category or dietary requirements
- View nutritional information

## Order Management
- Create orders with custom items
- Track order status
- Order history

## Nutritional Profiles
- Create and manage user nutrition profiles
- Track dietary preferences
- Special diet management

## Admin Interface
- Manage users and orders
- Update menu items
- View analytics and reports

## Contact Management
- Submit contact messages
- Admin messaging dashboard
