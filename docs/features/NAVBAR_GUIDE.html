Guide d'Utilisation

Structure HTML de Base
<nav class="navbar navbar-expand-lg navbar-light bg-light sticky-top shadow-sm nav-enhanced">
    <div class="container-fluid px-md-5">
        <!-- Logo -->
        <a class="navbar-brand" href="#">
            <i class="fas fa-leaf"></i>
            <span>Fresh</span> & <span>Green</span>
        </a>

        <!-- Mobile Toggle -->
        <button class="navbar-toggler" type="button" data-bs-toggle="collapse">
            <i class="fas fa-bars fs-5"></i>
        </button>

        <!-- Navigation Links -->
        <div class="collapse navbar-collapse" id="navbarNav">
            <ul class="navbar-nav ms-auto">
                <li class="nav-item">
                    <a class="nav-link nav-link-enhanced" href="#">
                        <i class="bi bi-home"></i>Accueil
                    </a>
                </li>
                <!-- ... plus de liens ... -->
            </ul>
        </div>
    </div>
</nav>
Classes CSS Principales
  • .nav-enhanced - Style principal de la navbar
  • .nav-link-enhanced - Style des liens de navigation
  • .navbar-brand - Style du logo
  • .dropdown-menu - Style du dropdown menu
JavaScript Integration

Le fichier navbar-enhanced.js fournit:

  • Détection automatique du lien actif
  • Animations fluides des interactions
  • Gestion du dropdown mobile
  • Smooth scroll pour les ancres

Personnalisation

1. Modifier les Couleurs

Les couleurs peuvent être personnalisées en modifiant les variables CSS dans style.css:

:root {
    --vert-sauge: #9BBF8F;
    --vert-feuille: #5A7D5C;
    --vert-profond: #2E4A2F;
    --accent-miel: #D9B48B;
    /* ... autres variables ... */
}
2. Changer les Icônes

Utilisez Font Awesome 6 ou Bootstrap Icons:

<!-- Font Awesome -->
<i class="fas fa-icon-name"></i>

<!-- Bootstrap Icons -->
<i class="bi bi-icon-name"></i>
3. Appliquer des Thèmes

Utilisez les classes de thème dans navbar-themes.css:

<nav class="navbar nav-enhanced navbar-theme-dark">
<nav class="navbar nav-enhanced navbar-accent">
<nav class="navbar nav-enhanced navbar-lg navbar-strong">
4. Ajuster l'Espacement

Modifiez les variables CSS pour l'espacement:

.nav-link-enhanced {
    padding: 0.5rem 0.75rem !important;
    gap: 0.4rem;
}

Bonnes Pratiques

✅ À Faire
  • Utiliser les classes Bootstrap 5 natives
  • Inclure les attributs ARIA pour l'accessibilité
  • Optimiser les icônes pour les appareils mobiles
  • Tester la navbar sur différents écrans
  • Utiliser les variables CSS pour les couleurs
  • Implémenter le keyboard navigation
❌ À Éviter
  • Surcharger la navbar avec trop de liens
  • Utiliser des icônes mal dimensionnées
  • Ignorer l'accessibilité et le contraste
  • Ajouter des animations trop lentes
  • Faire des dropdowns trop profonds
Checklist de Performance
  • CSS optimisé avec variables CSS
  • Animations GPU-friendly
  • CDN pour les dépendances
  • Minification des assets
  • Lazy loading des images
  • Tests de performance
